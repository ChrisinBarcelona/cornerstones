    Suggested route

    Not sure where to start? This is one way through. Dip into the method bank whenever your sprint needs a method.

    1. 1

      Understand UX

      Start with the foundations: what UX really is and where it comes from.

      UX Deck: What is UX Design
    2. 2

      Learn Figma

      Work through Figma Basics in order, then Figma Advanced.

      Figma: Choose your Frame
    3. 3

      Practise every day

      Pick a Daily UI brief each session, starting with Sidebar.

      UI Practicals: Sidebar
    4. 4

      Run a sprint

      Pick from the method bank whatever your sprint's problem needs. Many teams start with a Lean UX Canvas.

      UX Method Bank: Lean UX Canvas
    5. 5

      Build something bigger

      Finish with a replica challenge and the Stage Play team project.

      UI Practicals: Glovo Replica Challenge
