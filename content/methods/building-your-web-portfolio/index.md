# Building your Web Portfolio

# 🪜 Stage: Retrospective

Turn your case studies into a live portfolio website, built in Framer.

# 👋 Context

Your case studies need a home. In Portfolio Week you design and build your own portfolio website in **Framer**, a no-code tool that turns designs into a live, responsive site. The case studies you wrote with the **Process Narrative** method, and the artifacts you gathered with **Cataloguing Artifacts**, go into a CMS (content management system), so every case study shares one consistent template.

Work like a real product sprint: plan a backlog, set up styles and components first, then build the pages, then fill them with your case studies.

# 🎯 Goal / Learning Outcome

- Set up a Framer site with three breakpoints (desktop, tablet, mobile), local styles and reusable components.
- Plan the build as a two-week backlog and work through it phase by phase.
- Build a CMS collection and one case-study template that every project uses.
- Publish a portfolio site with a landing page, an about section and your case studies.

# 🛠️ Main Exercise

Work through the sprint plan below. Each phase lists the goal, the tasks and the video playlist to watch for it (all videos are further down the page).

| Phase | Goal | Tasks | Lessons  |
| --- | --- | --- | --- |
| **Discovery** | Get familiar with no-code tools & Framer basics; Knowledge refresh; Planning for sprint | 1. Open and set up Framer file with 3 breakpoints.<br>2. Make 2-week backlog in Trello.<br>3. Create Moodboard. | 📘 Framer Fundamentals (Videos 1-15) |
| **Ideating** | Create moodboard; Add basic local styles in Figma/Framer; Define basic components | - Define main components/ingredients- Add styles to Framer file manually | 📘 Framer Fundamentals (Videos 15-32) |
| **CMS** | Build CMS; Design cards for case studies; Build case study template | - Create CMS with 2 sample projects- Add a collection section (project section) | 🗂️ CMS Videos |
| **Building – Part 1** | Build landing page layout (nav + hero + featured + about me + footer) | - Build components/ingredients- Apply styles- Set up layout template | 📌 Framer Additional |
| **Building – Part 2** | Continue landing page layout (projects/case studies section via CMS) | - Build components/ingredients- Apply styles- Set up layout template | 📌 Framer Additional |
| **Case Studies** | Create case studies template with CMS; Polish design | - Add case studies to CMS | 📌 Framer Additional |

**Before you start building**, sketch your **Sitemap** and some **Paper Wireframes** for the landing page and the case-study template.

# ⏱️ Estimated Duration

- 5 days (Portfolio Week, with the Framer workshops)

# ⚡ Tips

- Build the system first: styles and components, then pages.
- Design one case-study template in the CMS and reuse it for every project.
- Check all three breakpoints after every change, not at the end.
- Keep the landing page short; let the case studies do the talking.
- Publish early and share the link for feedback before the final week.
