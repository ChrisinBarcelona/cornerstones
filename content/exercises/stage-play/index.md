# Stage Play

## Directives

Working as a team, produce a UI from the schema provided.

## Parameters

- Use Master Components
- Use the iPhone 17 canvas provided
- Use the 8 Pt Grid system
- Use Nested Containment
- Use Auto Layout
- Use Text Properties
- Use Swap Properties

## Duration

- 5 days in Figma

## Schema

The reference below sets out the canvas and grid (416 × 986 px, 8 pt grid) and the components to build: navigation, log in, lists, modular cards, messages and AV video. Click it to open it full size.
