# Style Guides

A [style tile](http://styletil.es/) or style guide or brand guide is a 1-page document that allows a designer to communicate color styles, typography styles, and graphic element styles (i.e. photography, illustration, and/or icon styles). Oftentimes, if you are in a situation that calls for style tiles, you’ll want to present stakeholders with at least a couple of options so they can visualize the way the site or app may look. Style tiles are also used within design teams to ensure they’re not diving straight into UI without a plan. It shows that the decisions have already been made (often with the stakeholder), and allows a team to use the same styles throughout the product.

## What goes in a style guide

Style tiles include some or all of the following:

- logo
- brand keywords
- color style set approved by your mentor (including HEX or RGB codes, and the purpose of each color)
- typography (fonts, sizes, styles, and how to use each one)
- photography style or photo treatment guidelines
- icons and illustration style

## Style guides in Figma

In Figma, your style guide lives as **styles and variables**: colour, text, effect and grid styles that every screen uses. Change a style once and every screen updates, which is why you set it up before you design in high fidelity.

## Why it matters for UX

A style guide is where consistency starts. When colours, type and imagery are decided once and written down, every screen and every designer on the team uses the same language, and stakeholders can agree on the look before you build it.

## Try it: a one-page style tile (40 minutes)

1. Write three brand keywords for your project.
2. Choose a colour palette (primary, secondary, neutrals, success and error) with HEX values and the purpose of each.
3. Define your type: one or two typefaces with styles for H1, H2, body and caption.
4. Add an icon set and a sample photo style, then save everything as Figma styles.

## Key takeaways

- A style guide records colour, type, imagery and icon decisions in one place.
- Present stakeholders with options before you design in high fidelity.
- In Figma, turn it into styles and variables so every screen stays consistent.
