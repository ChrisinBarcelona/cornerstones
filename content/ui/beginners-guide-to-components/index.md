# Beginner’s Guide to Components

## What you'll build

A small component library, from a list of the elements your app repeats to published components you can reuse on every screen. Components are the foundation of every design system.

## Before you start

- You've finished [Beginner’s Guide to the 8 Point Grid System](beginners-guide-to-8-point-grid-system.html)
- Your colour and text styles set up
- About 1 hour

## Let's go

Welcome to the world of components, where efficiency meets creativity! In this guide you go from a components list → components → a library, which is how you get to high fidelity fast.

This process is all about productivity. Using components to build a comprehensive design system streamlines your workflow inexorably and enhances the overall design thinking process by allowing you to quickly pivot away from a design decision and introduce a new module into your UI when necessary. So, let's dive in and discover the magic of components. Open the file above in Figma and make your start!

## Step by step

1. Duplicate the file to your drafts.
2. **Components list:** write down every element your app repeats (buttons, inputs, cards, list items, navigation, icons).
3. **Atoms first:** build the smallest pieces as components, using Auto Layout and your colour and text styles. Shortcut: `Option + Cmd + K` on Mac, `Ctrl + Alt + K` on Windows.
4. **Variants:** combine related components into a component set with **Create component set**, for example a button with Default, Hover and Disabled.
5. **Build bigger pieces:** make cards and navigation from instances of your atoms, so a change to the atom updates everything.
6. **Library:** move your components onto their own page, then publish them as a library from the **Assets** panel so every file in your team can use them.
7. **Use them:** build one screen using only instances from the Assets panel. Never detach an instance; change the main component instead.

## Well done!

You can now:

- Turn a list of repeated elements into components
- Group related components into variants
- Publish components as a library and build screens from instances
