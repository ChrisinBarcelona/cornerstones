The technique of nesting containers is closely correlated to grids and so to go over the absolute basics, we are going to do a simple exercise on how to make to nest one container inside another. This technique relies upon a basic understanding of margins which was covered in the previous chapter. let’s get started!

1. Make a Frame

Start with a frame; We’ll be using an iPhone 15 Pro again.

2. Add First Column

Using the Layout grid panel, place a column on top of the frame;

and apply the following settings;

  • Count: 1
  • Margin: 24px

You should have something that looks like this;

3. Add First Row

Great! Again, using Layout grid, what we will do is add a row;

And apply the same settings;

  • Count: 1
  • Margin: 24px

So you have this;

Well done! Now we will add another column.

3. Add Second Column

Using the Layout grid once more, add your second column with the following settings;

  • Count: 1
  • Margin: 48px

You should have a frame like this;

4. Add Second Row

Using the Layout grid once more, add a second row with the following settings;

  • Count: 1
  • Margin: 48px

You should have a frame like this;

Well done! Let’s resize the frame into a square!

4. Resize Frame

Pinch the bottom of the frame and drag up or input 390 in the height field;

Apply these settings;

  • Width: 390px
  • Height: 390px

Fantastico! A perfect square!

Now you need to add some assets. Let’s do that now!

7. Create Frame

Create a Frame and put line it up over the outer container.

Notice; total layer size = 342 x 342px

8. Send Layer to Back

Lovely, and just send to back but right clicking on the layer and scrolling down to Send to back;

Optionally, move the layer back using the keyboard shortcut;

On Windows:

  • Nudge Back: Ctrl + Left square bracket

On Mac:

  • Nudge Back: Cmd + Left square bracket

Lovely! Finally, let’s Hide the grids;

9. Hide All Grids

By navigating over, once more, to Layout grid and click the close eye icon;

You should be left with a perfectly aligned masterpiece! Let’s add a background image!

10. Add Background Image

Click on your background layer;

Navigate to the Fill panel in the right hand sidebar;

Click the grey thumbnail;

Change Solid → Image

and choose you image;

You should end up with something that looks like this;

and add a border radius to the thumbnail;

Let’s drag in this adidas png icon;

Drag it into Figma and scale the icon to; 25px x 15px;

And finally align it to thumbnail;

The purpose of this exercise is to simply get you to become familiar and used to the notion of inner content areas. When we create negative space, it really allows our text and buttons to breath. New designers tend to never allow enough space for the to this should give you a hint about what way to go to create great UI designs.

If you want to learn how to make gradients, please continue, otherwise, you’re all done!

12. Add Gradient

Let’s add a few finishing touches … Based on what we have previously learned;

Let’s start! Add new shape layer

  • Make a Rectangle: R

Scale it to 342px x 342px

Drag it into your frame;

and use align to centre;

Now, nudge it toward the back;

On Windows:

  • Nudge Back: Ctrl + Left square bracket

On Mac:

  • Nudge Back: Cmd + Left square bracket

Just back far enough so that we can no longer see the image;

Now click on the layer;

Navigate to the Fill panel and again, click on the grey thumbnail;

Change the fill type from Solid → Linear

Amazing! Now we have a cool gradient! Let’s adjust the opacity;

12. Adjust Gradient

Select the top gradient node;

And drag the colour picker all the way down to absolute black;

  • Hex: #000000

Great Job! Now let’s drop the opacity down to 25%

and finito!
