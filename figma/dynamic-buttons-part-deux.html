What you'll build

Seven variants of your dynamic button (Default, Hover, Pressed, noStroke, withStroke, Disabled and Glass) in one component set, ready to use in any state.

Before you start

  • You've finished Dynamic Buttons Part One and have its button component
  • About 30 minutes

Let's go

Contents

  • Create component set with x7 variants
  • Add Colors
  • Change Variant Names

  • Test on Child 1. Select Parent Component

  1. Click Add Variant Button

  2. Make 6 more variants

  3. Colorise Buttons using HSL colours (one hue, different lightness for each state)

  1. Change Property Name to Button
  1. Rename variants to the following values
  • Default

  • Hover

  • Pressed

  • noStroke

  • withStroke

  • Disabled

  • Glass

    With glass effect, it’s necessary to add ‘effect’, change to ‘Glass’

  1. Test on Child Element

All Done!

Well done!

You can now:

  • Create a component set with several variants
  • Colour states consistently using HSL
  • Name variants clearly and test them on an instance
