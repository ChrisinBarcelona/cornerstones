Number Variables

Record your phone's frame, content areas, gaps and radii as number variables you can reuse.

So for this exercise, it's important that you download the Figma app from the app store and you get used to exclusively working in Frames as oppose to shape layers. The reason for this is because you cannot add auto-layout to shape layers. So things begin by setting up a frame that fits perfectly onto your phone. Let’s go!

  1. Create a new frame that will fit your own phone!

  2. Look at the Height and Width Properties. Take note of Width Value and Height Value

  3. Create Number Variable

  4. Input Full Width and Full Height values

As of 2026, Figma doesn’t allow you to create and switch Height and Width modes on the same variable. Hoping this to changing moving forward.

  1. Apply a one column grid to that frame with the following measurements applied: 16px Gutter / 16px Margin

  2. Measure the inner content area using a perfect square. This will be your first Content Area

    Now we will need to record that value in the spreadsheet.

  3. Enter those variables into the spreadsheet.

  • Use quick maths and make more Template Areas. You’ll need to record the following numbers:

  • Content Area 1 Width

    • Content Area 1 Height

    • Content Area 2 Width

    • Content Area 2 Height

    • Content Area 3 Width

    • Content Area 3 Height

    • Content Area 4 Width

    • Content Area 4 Height

    • Content Area 5 Width

    • Content Area 5 Height

  1. Save those Variables

  2. Create third template area. Take note of dimensions. Enter Variables

  3. Finish All Variables:

  • Global Settings
  • Pages
  • Content Areas
  • Buttons
  • Gaps

  • Radius

  1. For sure, the hardest thing to understand is the content areas as there will be five of them but some of them share similar properties, namely the width.

  2. Lastly, run some tests on the mobile, add some variables
